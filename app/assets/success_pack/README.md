# Success-card memes (user-sourced)

T-005's production asset set isn't in yet (brief done, illustration pending
— see `docs/memeapp-meme-asset-brief.md`). Same deal as the onboarding and
roast-overlay asset folders: you download a meme and drop it in here;
nothing here is fetched by the build.

| File | Where it shows |
|---|---|
| `beaten.png` (or `.jpg`/`.gif`) | The "ESTIMATE BEATEN" card's meme box |
| `streak.png` (or `.jpg`/`.gif`) | The streak-milestone card's meme box |

Suggested mood: triumphant/self-satisfied, not smug at the user — this is
the one surface in the whole app that's on the user's side (PRD: "wins get
a share button, roasts don't"). Success Kid, "well that escalated
quickly"-adjacent but proud, that kind of energy.

Landscape / roughly 3:2 reads best, same as the roast-overlay meme box.
Missing file → the box is hidden entirely, never a broken-image icon; a
missing meme must never block sharing the card.
