What Bonked collects

Bonked is a personal screen-time limiter: you pick which apps to watch and set a daily time budget for each. To do that, the app needs to know when a watched app is open and for how long.

Usage of the apps you choose to watch

Using Android's Usage Access permission, Bonked detects when one of your own chosen watched apps comes to the foreground and measures how long you've been in it, purely to show you a reminder when your own limit is hit. This is read locally with UsageStatsManager — Bonked never reads usage data for apps you haven't explicitly added to your watch list, and this data is not uploaded anywhere.

Anonymous product analytics

If the build you're running has analytics configured, Bonked logs a small, fixed set of events — things like "onboarding step completed" or "a limit reminder was shown, and how the session ended" — to help us understand whether the app is working. Every event is checked in code against a strict allowlist before it can be sent; nothing outside that list is ever included, and free text is never one of the allowed fields.

Third parties Bonked talks to

GIPHY — reaction GIFs

shared When a roast fires, Bonked sends one short, fixed "mood" label — one of about eight bundled strings, such as side eye or stonks — to GIPHY's public search API (api.giphy.com) over HTTPS, to fetch a matching reaction GIF. This is not your usage data and not anything you typed; it's chosen purely by which roast template fired. GIPHY's own "content was displayed" callback also fires as part of loading that GIF, which is GIPHY tracking its own content, not something Bonked adds. See GIPHY's privacy policy.

PostHog — anonymous analytics

shared, if enabled Only the allowlisted, non-identifying events listed above may be sent to PostHog, our analytics provider, and only in builds where we've configured it. See PostHog's privacy policy.

GitHub Releases — roast pack updates

no user data sent Bonked periodically checks a static file hosted on GitHub Releases to see whether new roast jokes are available, and downloads them if so. This is a plain, anonymous file download — no usage data, identifiers, or anything about you is included in that request.

Bonked never requests broad package visibility — it only ever resolves the apps you could plausibly pick in the app picker via Android's standard launcher-app query, not full device package access.

Storage & retention

Everything Bonked stores — your watched app list, limits, usage history, and any queued analytics events — lives in a local database on your device. There is no cloud account and no server-side copy. Uninstalling Bonked removes all of it. Analytics events, when enabled, are queued on-device and sent in small batches; once sent, we retain them only as long as needed to understand product usage, and never resell or repurpose them.

What Bonked does not collect

  • No name, email, phone number, or any account — Bonked has no sign-in.
  • No location, contacts, financial or health information.
  • No photos, videos, microphone, or camera access.
  • No message content, browsing history, or content from apps other than the on/off timing of the specific apps you chose to watch.
  • Anything you type into Bonked (like a reason for opening an app) stays on your device — it is never sent to GIPHY, PostHog, or anyone else.

Children's privacy

Bonked is a general-audience productivity tool and is not directed at children under 13. It does not knowingly collect personal information from children.

Changes to this policy
